## Entry

> One star. He fills my bowl, then hogs MY laptop typing all day. I knocked his coffee off the table and somehow I'm still the problem.

## Run

```sh
python3 main.py
```

Writes the entry text to `/output/entry.txt` (and a local `entry.txt` copy).
Standard library only, no network, deterministic — the same text every run.
